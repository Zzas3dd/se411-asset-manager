# Asset Manager

SE411 Project Part 1 (Fall 2026-27). A React app for managing company computers.

## Features

- Menu to move between pages
- View all assets
- Add, edit and delete assets
- About page with the team members

## How to run

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## How to run the tests

```bash
npm test
```
